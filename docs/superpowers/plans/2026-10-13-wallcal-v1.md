# WallCal v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `wallcal-card`, a Home Assistant Lovelace week-view wall calendar with optional moon-phase and cycle overlays, fully themable from YAML.

**Architecture:** One Lit custom element (`src/wallcal-card.ts`) composes pure, DOM-free modules (dates, week range, moon, cycle, formatting, config, theme tokens, event normalisation) and stateless Lit template functions (top bar, day column, chips, ring, moon icon). Events come from HA's REST calendar API; everything else is computed in the browser.

**Tech Stack:** TypeScript 7 (`tsc --noEmit` for type checking only), Lit 3 (no decorators), Vite 8 library mode (bundle + dev server), Vitest 5 + happy-dom.

**Spec:** `docs/superpowers/specs/2026-10-13-wallcal-design.md`

## Global Constraints

- Custom element name `wallcal-card`; dashboards reference it as `type: custom:wallcal-card`.
- Output is a single ES module `dist/wallcal-card.js` with Lit bundled in (HA does not expose Lit to cards).
- No TypeScript decorators: reactive state uses `static properties` plus `declare` fields.
- Event data (titles) is rendered only through Lit text bindings. Never `unsafeHTML`, `innerHTML`, or `.innerHTML=` with event data.
- Pure modules (`src/date.ts`, `src/week.ts`, `src/astro/*`, `src/cycle/*`, `src/format.ts`, `src/config.ts`, `src/theme/presets.ts`, `src/data/events.ts`) must not import `lit` or touch the DOM.
- Day arithmetic only through `src/date.ts` helpers (calendar-date based); never add multiples of 86 400 000 ms to move between days.
- Tests run with `TZ=Europe/Prague` (set in the npm script) so DST cases are deterministic.
- UI strings are English in v1; dates, weekdays and times are localised via `Intl` with `hass.locale.language`.
- **Performance on old wall tablets is a requirement** (spec §9). Browser floor Chrome/WebView 87 and Safari/iOS 14: the build targets `['chrome87', 'safari14']`; CSS must not use `color-mix()`, container queries or `:has()`. Translucent tints use an opacity pseudo-element layer.
- Unrelated `hass` updates must cause neither a re-render nor a fetch. No animations, transitions, blur or per-second timers. Cache `Intl.DateTimeFormat` instances. Bundle under 30 KB gzipped.
- Code comments only for non-obvious "why" (repo owner's rule).
- Commit messages: no `Co-Authored-By` or `Claude-Session` trailers (repo owner's rule).

## Review Focus

1. `period.last_period` arriving as a JS `Date` (UTC midnight) or an ISO datetime string instead of `"2026-10-02"`, because HA's YAML handling may convert unquoted dates. Must resolve to the intended local calendar date. → Task 7 tests.
2. Quick prev/next taps whose fetch responses arrive out of order. The card must never show an older request's events after a newer one landed. → Task 10 test.
3. Weekend in `days: 5` mode. Saturday/Sunday must show the coming Mon–Fri, not the week that just ended. → Task 2 tests.
4. Event title containing HTML (anyone who can send a calendar invite controls it). Must render as literal text, with no elements created. → Task 9 test.
5. Tablet left on across midnight for days. "Today" must move, and the visible week must follow if it was the current week. → Task 10 test.

export type Weekday = 0 | 1 | 2 | 3 | 4 | 5 | 6;

const MS_PER_DAY = 86_400_000;

export function startOfDay(d: Date): Date {
  return new Date(d.getFullYear(), d.getMonth(), d.getDate());
}

export function addDays(d: Date, n: number): Date {
  return new Date(d.getFullYear(), d.getMonth(), d.getDate() + n);
}

export function daysBetween(from: Date, to: Date): number {
  const a = Date.UTC(from.getFullYear(), from.getMonth(), from.getDate());
  const b = Date.UTC(to.getFullYear(), to.getMonth(), to.getDate());
  return Math.round((b - a) / MS_PER_DAY);
}

export function isSameDay(a: Date, b: Date): boolean {
  return daysBetween(a, b) === 0;
}

export function parseLocalDate(value: string): Date | null {
  const match = /^(\d{4})-(\d{2})-(\d{2})$/.exec(value);
  if (!match) return null;
  const year = Number(match[1]);
  const month = Number(match[2]) - 1;
  const day = Number(match[3]);
  const date = new Date(year, month, day);
  return date.getMonth() === month && date.getDate() === day ? date : null;
}

export function msUntilNextMidnight(now: Date): number {
  return addDays(now, 1).getTime() - now.getTime();
}
```

import { addDays, startOfDay, type Weekday } from './date';

export type DayCount = 5 | 7;

export function weekDates(anchor: Date, days: DayCount, firstDay: Weekday): Date[] {
  const day = startOfDay(anchor);
  const dow = day.getDay();
  let offset: number;
  if (days === 5) {
    offset = dow === 6 ? 2 : dow === 0 ? 1 : 1 - dow;
  } else {
    offset = -((dow - firstDay + 7) % 7);
  }
  const first = addDays(day, offset);
  return Array.from({ length: days }, (_, i) => addDays(first, i));
}

export function isSameWeek(a: Date, b: Date, days: DayCount, firstDay: Weekday): boolean {
  return weekDates(a, days, firstDay)[0].getTime() === weekDates(b, days, firstDay)[0].getTime();
}
```

```ts
export type MoonPhaseName =
  | 'new'
  | 'waxing_crescent'
  | 'first_quarter'
  | 'waxing_gibbous'
  | 'full'
  | 'waning_gibbous'
  | 'last_quarter'
  | 'waning_crescent';

export interface MoonPhase {
  age: number;
  fraction: number;
  illumination: number;
  waxing: boolean;
  phase: MoonPhaseName;
}

export const SYNODIC_MONTH = 29.530588853;
const REFERENCE_NEW_MOON = Date.UTC(2000, 0, 6, 18, 14);
const MS_PER_DAY = 86_400_000;

const PHASES: MoonPhaseName[] = [
  'new',
  'waxing_crescent',
  'first_quarter',
  'waxing_gibbous',
  'full',
  'waning_gibbous',
  'last_quarter',
  'waning_crescent',
];

export const PHASE_LABELS: Record<MoonPhaseName, string> = {
  new: 'New moon',
  waxing_crescent: 'Waxing crescent',
  first_quarter: 'First quarter',
  waxing_gibbous: 'Waxing gibbous',
  full: 'Full moon',
  waning_gibbous: 'Waning gibbous',
  last_quarter: 'Last quarter',
  waning_crescent: 'Waning crescent',
};

export function moonPhase(date: Date): MoonPhase {
  const noon = new Date(date.getFullYear(), date.getMonth(), date.getDate(), 12);
  const days = (noon.getTime() - REFERENCE_NEW_MOON) / MS_PER_DAY;
  const age = ((days % SYNODIC_MONTH) + SYNODIC_MONTH) % SYNODIC_MONTH;
  const fraction = age / SYNODIC_MONTH;
  return {
    age,
    fraction,
    illumination: (1 - Math.cos(2 * Math.PI * fraction)) / 2,
    waxing: fraction < 0.5,
    phase: PHASES[Math.floor(fraction * 8 + 0.5) % 8],
  };
}

export function litOnRight(phase: MoonPhase, hemisphere: 'north' | 'south'): boolean {
  return phase.waxing !== (hemisphere === 'south');
}

const round = (n: number) => Number(n.toFixed(2));

// Lit area = outer half-disc on the lit side + an elliptical terminator back to the top.
// SVG sweep flag 1 = clockwise on screen; the terminator bulges toward the lit side for a
// crescent and away from it for a gibbous moon.
export function moonPath(illumination: number, litRight: boolean, r: number, cx: number, cy: number): string {
  const rx = round(Math.abs(1 - 2 * illumination) * r);
  const gibbous = illumination > 0.5;
  const outerSweep = litRight ? 1 : 0;
  const innerSweep = litRight === gibbous ? 1 : 0;
  return `M ${cx} ${cy - r} A ${r} ${r} 0 0 ${outerSweep} ${cx} ${cy + r} A ${rx} ${r} 0 0 ${innerSweep} ${cx} ${cy - r} Z`;
}
```

import { daysBetween } from '../date';

export interface CycleInput {
  starts: Date[];
  cycleLength: number;
  periodLength: number;
}

export interface CycleDay {
  day: number;
  length: number;
  isPeriod: boolean;
  isFertile: boolean;
  isOvulation: boolean;
}

export const LUTEAL_LENGTH = 14;
export const FERTILE_DAYS_BEFORE_OVULATION = 5;

export function cycleInfo(date: Date, input: CycleInput): CycleDay | null {
  let anchor: Date | null = null;
  for (const start of input.starts) {
    if (daysBetween(start, date) >= 0 && (!anchor || start.getTime() > anchor.getTime())) anchor = start;
  }
  if (!anchor) return null;

  const day = (daysBetween(anchor, date) % input.cycleLength) + 1;
  const ovulationDay = input.cycleLength - LUTEAL_LENGTH;
  return {
    day,
    length: input.cycleLength,
    isPeriod: day <= input.periodLength,
    isOvulation: day === ovulationDay,
    isFertile: day >= ovulationDay - FERTILE_DAYS_BEFORE_OVULATION && day <= ovulationDay,
  };
}

```ts
import type { HassLocale } from './ha-types';

export type TimeFormat = '12' | '24' | 'auto';
export type HourCycle = 'h12' | 'h23';
export type TitleMode = 'month' | 'range';

// Constructing an Intl.DateTimeFormat costs far more than formatting with one; old tablets feel it.
const cache = new Map<string, Intl.DateTimeFormat>();

export function formatter(language: string | undefined, options: Intl.DateTimeFormatOptions): Intl.DateTimeFormat {
  const key = `${language ?? ''}|${JSON.stringify(options)}`;
  let instance = cache.get(key);
  if (!instance) {
    instance = new Intl.DateTimeFormat(language, options);
    cache.set(key, instance);
  }
  return instance;
}

export function resolveHourCycle(timeFormat: TimeFormat, locale: HassLocale): HourCycle {
  if (timeFormat === '12') return 'h12';
  if (timeFormat === '24') return 'h23';
  if (locale.time_format === '12') return 'h12';
  if (locale.time_format === '24') return 'h23';
  const language = locale.time_format === 'system' ? undefined : locale.language;
  const cycle = formatter(language, { hour: 'numeric' }).resolvedOptions().hourCycle;
  return cycle === 'h11' || cycle === 'h12' ? 'h12' : 'h23';
}

export function formatTime(date: Date, language: string, hourCycle: HourCycle): string {
  return formatter(language, { hour: 'numeric', minute: '2-digit', hourCycle }).format(date);
}

export function formatWeekday(date: Date, language: string): string {
  return formatter(language, { weekday: 'short' }).format(date);
}

export function formatTitle(dates: Date[], mode: TitleMode, language: string): string {
  const first = dates[0];
  const last = dates[dates.length - 1];
  if (mode === 'range') {
    return formatter(language, { month: 'short', day: 'numeric' }).formatRange(first, last);
  }
  if (first.getMonth() === last.getMonth() && first.getFullYear() === last.getFullYear()) {
    return formatter(language, { month: 'long', year: 'numeric' }).format(first);
  }
  return formatter(language, { month: 'short', year: 'numeric' }).formatRange(first, last);
}
```

  align: 'left' | 'center';
  navigation: boolean;
  idle_return: number;

  enabled: boolean;
  last_period: Date | null;
  cycle_length: number;
  period_length: number;
  show_fertile: boolean;
  show_ovulation: boolean;
}

export interface WallCalConfig {
  entities: EntityConfig[];
  days: DayCount;
  first_day: Weekday;
  time_format: TimeFormat;
  refresh_interval: number;
  header: HeaderConfig;
  moon: MoonConfig;
  period: PeriodConfig;
  theme: ThemeName;
  style: Partial<Record<Token, string>>;
  font_url: string | null;

export const ENTITY_PALETTE = ['#7F77DD', '#1D9E75', '#D85A30', '#378ADD', '#D4537E', '#BA7517'];

const WEEKDAYS = ['sunday', 'monday', 'tuesday', 'wednesday', 'thursday', 'friday', 'saturday'] as const;
const TIME_FORMATS = ['12', '24', 'auto'] as const;
const ENTITY_ID = /^calendar\.[a-z0-9_]+$/;
const FONT_URL = /^(https:\/\/|\/(?!\/))/;

type Raw = Record<string, unknown>;

export function normalizeConfig(input: unknown): WallCalConfig {
  if (!input || typeof input !== 'object' || Array.isArray(input)) {
    throw new Error('WallCal configuration must be a mapping');
  }
  const raw = input as Raw;
  const header = section(raw.header, 'header');
  const moon = section(raw.moon, 'moon');
  const period = section(raw.period, 'period');

  const daysValue = int(raw.days, 7, 5, 7, 'days');
  if (daysValue === 6) throw new Error('days must be 5 or 7');
  const days: DayCount = daysValue === 5 ? 5 : 7;

  const periodEnabled = bool(period.enabled, false, 'period.enabled');
  const lastPeriod = toLocalDate(period.last_period, 'period.last_period');
  if (periodEnabled && !lastPeriod) {
    throw new Error('period.last_period is required when period.enabled is true (format YYYY-MM-DD)');
  }

  const { style, fontUrl } = parseStyle(section(raw.style, 'style'));

  return {

    refresh_interval: int(raw.refresh_interval, 300, 60, 86_400, 'refresh_interval'),
    header: {
      show: bool(header.show, true, 'header.show'),
      title: oneOf(header.title, ['month', 'range', 'none'] as const, 'month', 'header.title'),
      align: oneOf(header.align, ['left', 'center'] as const, 'left', 'header.align'),
      navigation: bool(header.navigation, true, 'header.navigation'),
      idle_return: int(header.idle_return, 60, 0, 86_400, 'header.idle_return'),
    },
    moon: {

      show_name: bool(moon.show_name, false, 'moon.show_name'),
      hemisphere: oneOf(moon.hemisphere, ['north', 'south'] as const, 'north', 'moon.hemisphere'),

      show_fertile: bool(period.show_fertile, true, 'period.show_fertile'),
      show_ovulation: bool(period.show_ovulation, true, 'period.show_ovulation'),
    },
    theme: oneOf(raw.theme, THEME_NAMES, 'default', 'theme'),
    style,
    font_url: fontUrl,
  };
}

function section(value: unknown, path: string): Raw {
  if (value === undefined || value === null) return {};
  if (typeof value !== 'object' || Array.isArray(value)) throw new Error(`${path} must be a mapping`);
  return value as Raw;
}

function bool(value: unknown, fallback: boolean, path: string): boolean {
  if (value === undefined || value === null) return fallback;
  if (typeof value === 'boolean') return value;
  throw new Error(`${path} must be true or false`);
}

function int(value: unknown, fallback: number, min: number, max: number, path: string): number {
  if (value === undefined || value === null || value === '') return fallback;
  const n = typeof value === 'number' ? value : Number(value);
  if (!Number.isInteger(n) || n < min || n > max) {
    throw new Error(`${path} must be a whole number from ${min} to ${max}`);
  }
  return n;
}

function oneOf<T extends string>(value: unknown, options: readonly T[], fallback: T, path: string): T {
  if (value === undefined || value === null) return fallback;
  const s = String(value).toLowerCase();
  if ((options as readonly string[]).includes(s)) return s as T;
  throw new Error(`${path} must be one of: ${options.join(', ')}`);
}

// HA's YAML handling can hand an unquoted date over as a Date at UTC midnight or as an ISO
// datetime string; both must mean the calendar date the user typed.
function toLocalDate(value: unknown, path: string): Date | null {
  if (value === undefined || value === null || value === '') return null;
  if (value instanceof Date && !Number.isNaN(value.getTime())) {
    return new Date(value.getUTCFullYear(), value.getUTCMonth(), value.getUTCDate());
  }
  if (typeof value === 'string') {
    const parsed = parseLocalDate(value.slice(0, 10));
    if (parsed) return parsed;
  }
  throw new Error(`${path} must be a date like 2026-10-02`);
}

function parseEntities(value: unknown): EntityConfig[] {
  if (!Array.isArray(value) || value.length === 0) {
    throw new Error('entities must list at least one calendar entity');
  }
  return value.map((item, i) => {
    const obj: Raw = typeof item === 'string' ? { entity: item } : section(item, `entities[${i}]`);
    const entity = String(obj.entity ?? '');
    if (!ENTITY_ID.test(entity)) {
      throw new Error(`entities[${i}]: "${entity}" is not a calendar entity id (expected calendar.something)`);
    }
    const color = obj.color === undefined ? ENTITY_PALETTE[i % ENTITY_PALETTE.length] : String(obj.color);
    return obj.name === undefined ? { entity, color } : { entity, color, name: String(obj.name) };
  });
}

function parseStyle(raw: Raw): { style: Partial<Record<Token, string>>; fontUrl: string | null } {
  const style: Partial<Record<Token, string>> = {};
  let fontUrl: string | null = null;
  for (const [key, value] of Object.entries(raw)) {
    if (key === 'font_url') {
      const url = String(value);
      if (!FONT_URL.test(url)) throw new Error('style.font_url must start with https:// or /');
      fontUrl = url;
    } else if ((TOKENS as readonly string[]).includes(key)) {
      style[key as Token] = typeof value === 'number' ? `${value}px` : String(value);
    } else {
      throw new Error(`style.${key} is not a known style option. Known: ${[...TOKENS, 'font_url'].join(', ')}`);
    }
  }
  return { style, fontUrl };
}

import type { EntityConfig } from '../config';
import { addDays, parseLocalDate, startOfDay } from '../date';
import type { HomeAssistant } from '../ha-types';

export interface HaCalendarEvent {
  summary?: string;
  start: { date?: string; dateTime?: string };
  end: { date?: string; dateTime?: string };
}

export interface WallCalEvent {
  entity: string;
  title: string;
  start: Date;
  end: Date;
  allDay: boolean;
  color: string;
}

export interface DayEvent {
  event: WallCalEvent;
  continued: boolean;
}

export interface FetchResult {
  entity: string;
  events?: WallCalEvent[];
  error?: string;
}

export interface EventCache {
  rangeKey: string;
  byEntity: Record<string, WallCalEvent[]>;
}

export function normalizeEvent(raw: HaCalendarEvent, source: EntityConfig): WallCalEvent | null {
  const base = { entity: source.entity, title: raw.summary?.trim() || '(no title)', color: source.color };

  if (raw.start?.date) {
    const start = parseLocalDate(raw.start.date);
    if (!start) return null;
    const end = raw.end?.date ? parseLocalDate(raw.end.date) : null;
    return { ...base, start, end: end && end.getTime() > start.getTime() ? end : addDays(start, 1), allDay: true };
  }

  if (raw.start?.dateTime) {
    const start = new Date(raw.start.dateTime);
    if (Number.isNaN(start.getTime())) return null;
    const end = raw.end?.dateTime ? new Date(raw.end.dateTime) : start;
    const validEnd = !Number.isNaN(end.getTime()) && end.getTime() >= start.getTime() ? end : start;
    return { ...base, start, end: validEnd, allDay: false };
  }

  return null;
}

export function eventsForDay(events: WallCalEvent[], day: Date): DayEvent[] {
  const dayStart = startOfDay(day).getTime();
  const dayEnd = addDays(day, 1).getTime();
  return events
    .filter((e) => {
      const start = e.start.getTime();
      const end = e.end.getTime();
      return start < dayEnd && (end > dayStart || start >= dayStart);
    })
    .map((event) => ({ event, continued: !event.allDay && event.start.getTime() < dayStart }))
    .sort(compareDayEvents);
}

function compareDayEvents(a: DayEvent, b: DayEvent): number {
  if (a.event.allDay !== b.event.allDay) return a.event.allDay ? -1 : 1;
  if (a.continued !== b.continued) return a.continued ? -1 : 1;
  const byStart = a.event.start.getTime() - b.event.start.getTime();
  return byStart !== 0 ? byStart : a.event.title.localeCompare(b.event.title);
}

export async function fetchEvents(
  hass: HomeAssistant,
  entities: EntityConfig[],
  start: Date,
  end: Date,
): Promise<FetchResult[]> {
  const query = `start=${encodeURIComponent(start.toISOString())}&end=${encodeURIComponent(end.toISOString())}`;
  const settled = await Promise.allSettled(
    entities.map((e) => hass.callApi<HaCalendarEvent[]>('GET', `calendars/${e.entity}?${query}`)),
  );
  return settled.map((outcome, i) => {
    const source = entities[i];
    if (outcome.status === 'rejected') {
      return { entity: source.entity, error: `${source.entity}: ${errorMessage(outcome.reason)}` };
    }
    const events = outcome.value
      .map((raw) => normalizeEvent(raw, source))
      .filter((e): e is WallCalEvent => e !== null);
    return { entity: source.entity, events };
  });
}

export function mergeResults(prev: EventCache | null, rangeKey: string, results: FetchResult[]): EventCache {
  const kept = prev && prev.rangeKey === rangeKey ? prev.byEntity : {};
  const byEntity: Record<string, WallCalEvent[]> = {};
  for (const result of results) {
    if (result.events) byEntity[result.entity] = result.events;
    else if (kept[result.entity]) byEntity[result.entity] = kept[result.entity];
  }
  return { rangeKey, byEntity };
}

export function cachedEvents(cache: EventCache | null): WallCalEvent[] {
  return cache ? Object.values(cache.byEntity).flat() : [];
}

function errorMessage(error: unknown): string {
  if (error instanceof Error) return error.message;
  if (error && typeof error === 'object' && 'message' in error) return String(error.message);
  return String(error);
}

import { LitElement, html, nothing } from 'lit';
import { styleMap } from 'lit/directives/style-map.js';
import { renderDayColumn } from './components/day-column';
import { renderTopBar } from './components/top-bar';
import { normalizeConfig, type WallCalConfig } from './config';
import { cycleInfo, type CycleInput } from './cycle/predict';
import { cachedEvents, eventsForDay, fetchEvents, mergeResults, type EventCache } from './data/events';
import { addDays, isSameDay, msUntilNextMidnight, startOfDay } from './date';
import { formatTitle, resolveHourCycle } from './format';
import type { HomeAssistant } from './ha-types';
import { resolveTokens } from './theme/presets';
import { cardStyles } from './theme/styles';
import { isSameWeek, weekDates } from './week';

export class WallCalCard extends LitElement {
  static styles = cardStyles;

  static properties = {
    _config: { state: true },
    _anchor: { state: true },
    _today: { state: true },
    _cache: { state: true },
    _warning: { state: true },
  };

  declare _config?: WallCalConfig;
  declare _anchor: Date;
  declare _today: Date;
  declare _cache: EventCache | null;
  declare _warning: string | null;

  private _hass?: HomeAssistant;
  private _seen = new Map<string, string>();
  private _fetchSeq = 0;
  private _refreshTimer?: ReturnType<typeof setInterval>;
  private _midnightTimer?: ReturnType<typeof setTimeout>;
  private _idleTimer?: ReturnType<typeof setTimeout>;

  constructor() {
    super();
    this._today = startOfDay(new Date());
    this._anchor = this._today;
    this._cache = null;
    this._warning = null;
  }

  static getStubConfig(hass?: HomeAssistant): Record<string, unknown> {
    const first = Object.keys(hass?.states ?? {}).find((id) => id.startsWith('calendar.'));
    return { entities: [first ?? 'calendar.family'] };
  }

  setConfig(config: unknown): void {
    this._config = normalizeConfig(config);
    this._cache = null;
    this._seen.clear();
    loadFont(this._config.font_url);
    if (this.isConnected) {
      this._restartRefresh();
      void this._fetch();
    }
  }

  set hass(hass: HomeAssistant) {
    const previous = this._hass;
    this._hass = hass;
    if (!previous || previous.locale !== hass.locale) this.requestUpdate();
    if (!previous || this._calendarsChanged(hass)) void this._fetch();
  }

  get hass(): HomeAssistant | undefined {
    return this._hass;
  }

  getCardSize(): number {
    return 8;
  }

  getGridOptions(): Record<string, unknown> {
    return { columns: 'full', rows: 8, min_rows: 6 };
  }

  connectedCallback(): void {
    super.connectedCallback();
    this._restartRefresh();
    this._armMidnight();
    void this._fetch();
  }

  disconnectedCallback(): void {
    super.disconnectedCallback();
    clearInterval(this._refreshTimer);
    clearTimeout(this._midnightTimer);
    clearTimeout(this._idleTimer);
  }

  protected render() {
    const config = this._config;
    const hass = this._hass;
    if (!config || !hass) return nothing;

    const language = hass.locale?.language ?? 'en';
    const hourCycle = resolveHourCycle(config.time_format, hass.locale ?? { language, time_format: 'language' });
    const days = weekDates(this._anchor, config.days, config.first_day);
    const events = cachedEvents(this._cache);
    const cycleInput: CycleInput | null =
      config.period.enabled && config.period.last_period
        ? {
            starts: [config.period.last_period],
            cycleLength: config.period.cycle_length,
            periodLength: config.period.period_length,
          }
        : null;
    const tokens = { ...resolveTokens(config.theme, config.style), '--wallcal-days': String(config.days) };

    return html`<ha-card style=${styleMap(tokens)} @pointerdown=${() => this._touch()}>
      ${renderTopBar({
        header: config.header,
        title: config.header.title === 'none' ? '' : formatTitle(days, config.header.title, language),
        isCurrentWeek: this._isCurrentWeek(),
        warning: this._warning,
        onPrev: () => this._go(-7),
        onToday: () => this._go(null),
        onNext: () => this._go(7),
      })}
      <div class="grid">
        ${days.map((date) =>
          renderDayColumn({
            date,
            isToday: isSameDay(date, this._today),
            events: eventsForDay(events, date),
            language,
            hourCycle,
            moon: config.moon,
            period: config.period,
            cycle: cycleInput ? cycleInfo(date, cycleInput) : null,
          }),
        )}
      </div>
    </ha-card>`;
  }

  private _isCurrentWeek(): boolean {
    const config = this._config;
    return !config || isSameWeek(this._anchor, this._today, config.days, config.first_day);
  }

  private _calendarsChanged(hass: HomeAssistant): boolean {
    return (
      this._config?.entities.some(
        (e) => this._seen.get(e.entity) !== (hass.states[e.entity]?.last_changed ?? ''),
      ) ?? false
    );
  }

  private async _fetch(): Promise<void> {
    const config = this._config;
    const hass = this._hass;
    if (!config || !hass || !this.isConnected) return;

    const seq = ++this._fetchSeq;
    const days = weekDates(this._anchor, config.days, config.first_day);
    const start = days[0];
    const end = addDays(days[days.length - 1], 1);
    for (const e of config.entities) this._seen.set(e.entity, hass.states[e.entity]?.last_changed ?? '');

    const results = await fetchEvents(hass, config.entities, start, end);
    // A newer request (e.g. after a quick prev/next tap) supersedes this one.
    if (seq !== this._fetchSeq) return;

    this._cache = mergeResults(this._cache, `${start.getTime()}-${end.getTime()}`, results);
    const errors = results.flatMap((r) => (r.error ? [r.error] : []));
    this._warning = errors.length ? errors.join('\n') : null;
  }

  private _go(deltaDays: number | null): void {
    this._anchor = deltaDays === null ? this._today : addDays(this._anchor, deltaDays);
    this._touch();
    void this._fetch();
  }

  private _touch(): void {
    clearTimeout(this._idleTimer);
    const seconds = this._config?.header.idle_return ?? 0;
    if (seconds <= 0) return;
    this._idleTimer = setTimeout(() => {
      if (this._isCurrentWeek()) return;
      this._anchor = this._today;
      void this._fetch();
    }, seconds * 1000);
  }

  private _restartRefresh(): void {
    clearInterval(this._refreshTimer);
    if (!this._config) return;
    this._refreshTimer = setInterval(() => void this._fetch(), this._config.refresh_interval * 1000);
  }

  private _armMidnight(): void {
    clearTimeout(this._midnightTimer);
    this._midnightTimer = setTimeout(() => this._onMidnight(), msUntilNextMidnight(new Date()) + 1000);
  }

  private _onMidnight(): void {
    const followToday = this._isCurrentWeek();
    this._today = startOfDay(new Date());
    if (followToday) this._anchor = this._today;
    this._armMidnight();
    void this._fetch();
  }
}

function loadFont(url: string | null): void {
  if (!url) return;
  const existing = [...document.head.querySelectorAll<HTMLLinkElement>('link[data-wallcal-font]')];
  if (existing.some((link) => link.dataset.wallcalFont === url)) return;
  const link = document.createElement('link');
  link.rel = 'stylesheet';
  link.href = url;
  link.dataset.wallcalFont = url;
  document.head.append(link);
}

if (!customElements.get('wallcal-card')) customElements.define('wallcal-card', WallCalCard);

window.customCards = window.customCards ?? [];
if (!window.customCards.some((card) => card.type === 'wallcal-card')) {
  window.customCards.push({
    type: 'wallcal-card',
    name: 'WallCal',
    description: 'Week wall calendar with moon phase and cycle overlays',
    preview: false,
  });
}

console.info(
  `%c WALLCAL %c ${__WALLCAL_VERSION__} `,
  'background:#D4537E;color:#fff;border-radius:4px 0 0 4px',
  'background:#2C2C2A;color:#fff;border-radius:0 4px 4px 0',
);

# WallCal

A week-view wall calendar card for Home Assistant, designed for an always-on landscape tablet.
Clean by default, restylable from YAML, with optional moon phase and cycle overlays.

## Install

**HACS (custom repository):** HACS → Frontend → ⋮ → Custom repositories → add this repo as
*Dashboard*, install WallCal, reload the browser.

**Manual:** `npm install && npm run build`, copy `dist/wallcal-card.js` to `/config/www/`, then add
`/local/wallcal-card.js` as a JavaScript module under Settings → Dashboards → Resources.

## Configure

```yaml
type: custom:wallcal-card
entities:
  - entity: calendar.family
    color: "#7F77DD"
  - calendar.work
days: 7              # or 5 for Mon–Fri
first_day: monday
time_format: auto    # 12 | 24 | auto
header:
  title: month       # month | range | none
  navigation: true
  idle_return: 60
moon:
  enabled: true
period:
  enabled: true
  last_period: 2026-10-02
  cycle_length: 28
  period_length: 5
theme: paper         # default | paper | midnight
style:
  date_size: 36
  accent: "#D4537E"
```

Every option and style token is listed in
[the design spec](docs/superpowers/specs/2026-10-13-wallcal-design.md#6-configuration-reference).

## Please note

- **Privacy:** the period settings are stored in the dashboard configuration. Anyone who can open
  that dashboard in Home Assistant can read them, and they are included in backups.
- **Predictions are estimates.** Expected period, fertile window and ovulation come from a fixed
  cycle length and the standard 14-day luteal phase. They are a calendar hint, not medical advice
  and not a contraception method.
- Moon phase uses the mean lunar cycle and can be off by up to about half a day.
- Built for old wall tablets: works on Chrome / Android WebView 87+ and Safari / iOS 14+, with no
  animations or background work beyond a refresh every few minutes.
